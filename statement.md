# Project Statement

## Problem Statement
Managing personal contacts manually on paper or via unorganized notes is inefficient, error-prone, and lacks data security and persistent storage.

## Scope of the Project
A lightweight command-line Python application that allows users to securely authenticate, store, search, and manage personal contact details with reliable local file persistence and strict phone number validation.

## Target Users
* Students and individuals looking for a simple address book utility.
* Developers learning modular Python programming and file handling.

## High-Level Features
* **User Authentication:** Secure registration and login.
* **Contact CRUD:** Add, view, search, and delete contacts.
* **Input Validation:** Ensures phone numbers accept digits only.
* **Persistent Storage:** Automatically saves user and contact data to local files.
